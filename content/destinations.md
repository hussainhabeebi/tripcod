## Book Now

Each **Book Now** button opens WhatsApp (`+971 52 931 9100`) with a prefilled message, the same pattern as the home page:

```
https://wa.me/971529319100?text=Hi, I'm interested in booking a trip to {Destination} for AED {Price}. Please share more details.
```

The text must be URL-encoded, for example Thailand:

```
https://wa.me/971529319100?text=Hi,%20I%27m%20interested%20in%20booking%20a%20trip%20to%20Thailand%20for%20AED%20800.%20Please%20share%20more%20details.
```
